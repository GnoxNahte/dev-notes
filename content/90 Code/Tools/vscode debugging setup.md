## c++ debugging vscode

Compile all files from the active file's folder and make it available to debug.
Need to create [[#.vscode/launch.json]] and [[#.vscode/task.json]] files

### .vscode/task.json

```json
{
    "tasks": [
        {
            "type": "cppbuild",
            "label": "Custom C/C++: g++-13 build active file",
            "command": "/usr/bin/g++-13",
            "args": [
                "-fdiagnostics-color=always",
                "-g",
                "${fileDirname}/*.cpp",
                "-o",
                "${fileDirname}/${fileBasenameNoExtension}.out"
            ],
            "options": {
                "cwd": "${fileDirname}"
            },
            "problemMatcher": [
                "$gcc"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            },
            "detail": "Task generated by Debugger."
        }
    ],
    "version": "2.0.0"
}
```

This runs first, building the `.out` file.

Main parts:

- `"command"` - Run `g++`
- In `"args"`
  - `"${fileDirname}/*.cpp"` - Get all `*.cpp` files from the current folder
  - `"-o"`, `"${fileDirname}/${fileBasenameNoExtension}.out"` - Output it to the current folder, at `<file-name>.out`

### .vscode/launch.json

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "C++ Debug",
            "type": "cppdbg",
            "request": "launch",
            "program": "${fileDirname}/${fileBasenameNoExtension}.out",
            "args": [],
            "stopAtEntry": false,
            "cwd": "${fileDirname}",
            "environment": [],
            "externalConsole": false,
            "MIMode": "gdb",
            "setupCommands": [
                {
                    "description": "Enable pretty-printing for gdb",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                }
            ],
            "preLaunchTask": "C++: build active file",
            "miDebuggerPath": "/usr/bin/gdb"
        }
    ]
}
```

This runs the generated `.out` file and setups `gdb`

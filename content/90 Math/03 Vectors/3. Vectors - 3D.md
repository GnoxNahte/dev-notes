## Lines
### Notation
A line in 3D is determined by a point $P=(x_{0},y_{0},z_{0})$ and a direction vector $\vec{d}=\begin{bmatrix}d_{1}\\d_{2}\\d_{3}\end{bmatrix}$
$$\vec{x}=P+t\vec{d}$$

> [!NOTE]
> -  This is DIFFERENT from [[90 Math/03 Vectors/3. Vectors - 3D#Planes]]
> - Since it only has 1 direction vector
### Quick normal vector in 3D
> [!info] Lines in 3D has infinite number of normal vectors

Steps (Similar to [[90 Math/03 Vectors/1. Vector - Basics (2D)#Making a normal vector\|2D]]):
- Set one of the coords to 0,
- Swap the other 2 coords
- Negate one of them

> [!EXAMPLE] 
> $\vec{d}=\begin{bmatrix}2\\3\\4\end{bmatrix}\ \ \ \to\ \ \ \vec{n}=\begin{bmatrix}0\\-4\\3\end{bmatrix}$

### Are 2 lines the same
Given $\vec{x}=P+s\vec{d_{1}}$ and $\vec{x}=Q+t\vec{d_{2}}$,
Same if (both true):
- $d_{1}\ || \ d_{2}$ 
- $P$ is a point on $\vec{x}=Q+t\vec{d_{2}}$ 

## Planes
### Notation

#### Vector equation
![[90 Math/03 Vectors/Drawings/Vector 3D - Drawings.excalidraw#^frame=sFtxo_9lGyUeZgL6p4p4R]]
Using 2 direction vectors,
$$\vec{x}=P+s\vec{u}+t\vec{v}$$
> [!WARNING] $\vec{u}$ and $\vec{v}$ cannot be parallel (it'll be a line if parallel)
##### 3 Points $\to$ Vector equation
Given $P, Q, R$,
$$
\vec{x}=P+s\vec{PQ}+t\vec{PR}
$$

##### Vector $\to$ Linear equation
Find $\vec{n}$ using $\vec{u}\times \vec{v}$ and then form the [[90 Math/03 Vectors/3. Vectors - 3D#Linear equation\|Linear equation]] 
$$
\begin{align}
\vec{n}&=\vec{u}\times \vec{v}\\
\vec{x}\cdot \vec{n}&=\vec{OP}\cdot \vec{n}
\end{align}
$$

#### Linear equation
![[90 Math/03 Vectors/Drawings/Vector 3D - Drawings.excalidraw#^clippedframe=QYHhZJA2784CWBfY8qvbj]]
To find a point on the plane, sub 2 variables to any value and solve the last value

> [!EXAMPLE] Find a point on plane
> Given $3x-2y-z=-4$, get a point on the plane
> Sub x=0, $y=0$,$$\begin{align}
> 0-0-z&=-4\\
> z=4 \\
> P=(0,0,4)
> \end{align}$$
> 

## Cross product
Used to find a vector that's perpendicular to the 2 vectors
$$
\vec{u}\times \vec{v}
=
\begin{bmatrix}u_{x}\\u_{y}\\u_{z}\end{bmatrix}\times \begin{bmatrix}v_{x}\\v_{y}\\v_{z}\end{bmatrix}
=
\begin{bmatrix}
u_{y}v_{z} - u_{z}v_{y} \\
u_{z}v_{x} - u_{x}v_{z} \\ 
u_{x}v_{y}-u_{y}v_{x}
\end{bmatrix}
$$
To check:
$$
(\vec{u}\times \vec{v})\cdot \vec{u}=0
$$
### Cross product Laws

| Law                                                                           | Note                                                                            |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| $\vec{u}\times \vec{v}=-(\vec{v}\times \vec{u})$                              | Swap $\vec{u}$ and $\vec{v}$ when negating                                      |
| $\vec{u}\times(\vec{v}+\vec{w})=\vec{u}\times \vec{v}+\vec{u}\times \vec{w}$  |                                                                                 |
| $(\vec{u}+\vec{v})\times \vec{w}=\vec{u}\times \vec{w}+\vec{v}\times \vec{w}$ |                                                                                 |
| $\vec{u}\times \vec{v}=\vec{0}$ if $\vec{u}$ and $\vec{v}$ are parallel       | Also applies to $\vec{u}\times \vec{u}=0$<br>as $\vec{u}$ is parallel to itself |
| $\vec{u}\times \vec{0}$                                                       |                                                                                 |
| $c(\vec{u}\times \vec{v})=(c\vec{u})\times \vec{v}=\vec{u}\times(c\vec{v})$   | The scalar ($c$) only applies to 1 vector                                       |

### Finding area of triangle with cross product
Given 3 points - P, Q and R
$$
\text{Area of} \ \triangle PQR=\frac{1}{2}||\vec{PQ}\times \vec{PR}||
$$

### Distances for Lines
#### Point to Line
![[90 Math/03 Vectors/Drawings/Vector 3D - Drawings.excalidraw#^clippedframe=3dQYN1Ll8p2SdxXdvXsnK]]

```tabs
--- Using cross product (recommended)
$$d(P,l)=\frac{\text{Area of parallelogram}}{||\vec{d}||}=\frac{||\vec{QP}\times \vec{d}||}{||\vec{d}||}$$

--- Using projection
$$
\begin{align}
\vec{QH}&=proj_{\vec{d}}{\vec{QP}} \\
\vec{HP}&=\vec{HQ}+\vec{QP} \\
d(P,l)&=||\vec{HP}||
\end{align}
$$
```

> [!WARNING] Cannot use the same method used in [[90 Math/03 Vectors/2. Vectors - Vector, Parametric equations (2D)#Point to line\|2D]] (projection onto normal)
> As a line in 3D has infinite normals

#### Line to Line
![[90 Math/03 Vectors/Drawings/Vector 3D - Drawings.excalidraw#^frame=zTvxfwf0lfz851_6roUGE\|1000]]
Given $l_{1}: \vec{x} = P+t\vec{d_{1}}$ and $l_{2}: \vec{x} = Q+t\vec{d_{2}}$,
1. If $d_{1}$ **parallel** to $d_{2}$ 
	- Distance = $d(P, l_{2})$ - [[90 Math/03 Vectors/3. Vectors - 3D#Point to Line]]  
2. If $d_{1}$ **intersect** $d_{2}$
	- Check by expanding to [[90 Math/03 Vectors/2. Vectors - Vector, Parametric equations (2D)#Parametric equation\|Parametric equation]] and solve simultaneous equation
	- Distance = 0
3. If $d_{1}$ **NOT parallel (skew)** to $d_{2}$,
	- Make a plane containing $l_{2}$ that's parallel to $l_{1}$ 
		- $\vec{n_{\alpha}} = \vec{d_{1}}\times \vec{d_{2}}$ 
		- $\alpha:\vec{x}\cdot\vec{n_{\alpha}}=Q\cdot \vec{n_{\alpha}}$ 
	- Distance = $d(P, \alpha)=||proj_{\vec{n_{\alpha}}}\vec{QP}||$ - [[90 Math/03 Vectors/3. Vectors - 3D#Plane to Point\|Plane to Point]] 
![[90 Math/03 Vectors/Drawings/Vector 3D - Drawings.excalidraw#^clippedframe=DLL13AVZm3Tb_z1uVC7df\|1000]]

### Distances for Planes
#### Plane to Point
Same as [[90 Math/03 Vectors/2. Vectors - Vector, Parametric equations (2D)#Finding shortest distance\|Shortest dist in 2D]]

Given  $\vec{x}=P+t\vec{d}$ and $Q(x, y, z)$ 
$$
\text{Dist from Q to line} =||proj_{\vec{n}}{\vec{PQ}}||
$$
![[90 Math/03 Vectors/Drawings/Vector 3D - Drawings.excalidraw#^frame=tbYOE1BhG1RVtKv24IAvV]]

#### Plane to Line, Plane to Plane
There are 2 cases:
- If plane/line is NOT parallel to the other plane, distance = 0
- If plane/line is parallel to the other plane, 
	- Treat it as [[90 Math/03 Vectors/3. Vectors - 3D#Distances for planes\|Plane to Point]] $\to$ Distance = $||proj_{\vec{n}_{\beta}}{\vec{QP}}||$

Examples:
```tabs
--- Plane to Plane
Given planes 
- $\alpha:P,\vec{n}_{\alpha} \implies\vec{x}_{\alpha}\cdot \vec{n}_{\alpha}=\vec{x}_{\alpha}\cdot \vec{OP}$ 
- $\beta:Q,\vec{n}_{\beta}\implies\vec{x}_{\beta}\cdot \vec{n}_{\beta}=\vec{x}_{\beta}\cdot \vec{OQ}$

There are 2 cases:
- $\alpha$ and $\beta$ intersect $\to$ $\vec{n}_{\alpha}$ NOT parallel to $\vec{n}_{\beta}$
$$
\text{So, }d(\alpha,\beta)=0
$$
- $\alpha$ and $\beta$ are parallel $\to$ $\vec{n}_{\alpha}$ parallel to $\vec{n}_{\beta}$ 
$$
d(\alpha,\beta)=d(P,\beta)=||proj_{\vec{n}_{\beta}}{\vec{QP}}||
$$
This is same as [[#Vectors in 3D#Plane to Point|Plane to Point]] (Treat the other plane as a point as it's parallel).
--- Plane to Line (css-class: pdf-page-break)
Given:
- $\alpha:P,\vec{n}_{\alpha} \implies\vec{x}_{\alpha}\cdot \vec{n}_{\alpha}=\vec{x}_{\alpha}\cdot \vec{OP}$ 
- $l:Q,\vec{d}\implies \vec{x}=Q+t\vec{d}$ 

There are 2 cases:
- $\alpha$ and $l$ intersect $\to$ $\vec{d}$ NOT $\perp$ $\vec{n}_{\alpha}$ 
$$
\text{So, }d(l,\alpha)=0
$$
- $\alpha$ and $l$ are parallel $\to$  $\vec{d} \perp \vec{n}_{\alpha}$ 
$$
d(l,\alpha)=d(P,\alpha)=||proj_{\vec{n}_{\alpha}}{\vec{QP}}||
$$

This is same as [[#Vectors in 3D#Plane to Point|Plane to Point]] (Treat the other line as a point as it's parallel).
```

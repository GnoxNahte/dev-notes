> [!NOTE] All notation is in 2D but it applies in 3D too

## Points

### Notation

$\mathbb{R}^2 =$ xy plane
$\mathbb{R}^3 =$ xyz plane

Let P = $(x_{1}, y_{1})$, Q = $(x_{2},y_{2})$,

### Mid point

$$
M_{PQ}=\frac{P+Q}{2}=\left( \frac{x_{1}+x_{2}}{2},\frac{y_{1}+y_{2}}{2}\right)
$$

### Distance

$$
d(P,Q)=\sqrt{ (x_{2}-x_{1})^2 + (y_{2}-y_{1})^2 }
$$

## Vectors

$\vec{PQ}=Q-P=\vec{OQ}-\vec{OP}$

Let $\vec{u}=\begin{bmatrix}u_{1} \\ u_{2}\end{bmatrix}$, $\vec{v}=\begin{bmatrix}v_{1} \\ v_{2}\end{bmatrix}$

### Adding & Subtracting vectors

See [[1E. Vector - Basics Explanation (2D)#Addition|Add]], [[1E. Vector - Basics Explanation (2D)#Subtraction|Subtract]] vectors

### Length

$$
\|\vec{a}\| = \sqrt{ x^{2}+y^{2} }
$$

### Dot product ([[1E. Vector - Basics Explanation (2D)#Dot product|Info]])

Represents [[#Vector Projection ( 1E. Vector - Basics Explanation (2D) Vector projection explanation Info )|projecting]] one vector onto the other multiplied by the length. See [3b1b video](https://www.youtube.com/watch?v=LyGKycYT2v0) for more info.

$$
\vec{a} \cdot \vec{b} = a_{1}b_{1}+a_{2}b_{2}
$$

If dot product > 0, angle between $\vec{a}$ and $\vec{b}$ is < $90^{\circ}$
If dot product = 0, angle between $\vec{a}$ and $\vec{b}$ is = $90^{\circ}$
If dot product < 0, angle between $\vec{a}$ and $\vec{b}$ is > $90^{\circ}$
Why? Because of $\cos^{-1}$

#### Angle between 2 vectors

$$
\theta=\cos^{-1}\left( \frac{\vec{a}\cdot\vec{b}}{\|\vec{a}\|\|\vec{b}\|} \right)
$$

#### Special cases

| Dot product |     Angle     |
| :---------: | :-----------: |
|     -1      | $180^{\circ}$ |
|      0      | $90^{\circ}$  |
|      1      |  $0^{\circ}$  |

> [!WARNING] ^ ONLY WORKS FOR UNIT VECTORS ^
> For dot product 1 and -1, $\vec{a}$ and $\vec{b}$ NEED to be unit vectors. For dot product 0, it doesn't matter

### Checking if vectors are parallel/perpendicular

#### For parallel

$\vec{u}=c\vec{v}$
$\vec{u}$ must be a scalar of $\vec{v}$

> [!NOTE] If $\vec{u}$ and $\vec{v}$ are unit vectors, can use [[#Special cases|Dot product, Special cases]]

#### For perpendicular

$\vec{u} \cdot \vec{v} = 0$
See [[#Special cases|Dot product, Special cases]]

### Making a normal vector

In 2 steps:

1. Swap $x$ and $y$
2. Negate either the $x$ or $y$
   - Negate $x$ to rotate $90^{\circ}$ anti-clockwise
   - Negate $y$ to rotate $90^{\circ}$ clockwise

> [!Example]
> $\vec{d} = \begin{bmatrix}2\\3\end{bmatrix}$
>
> $\vec{n}=\begin{bmatrix}3\\-2\end{bmatrix}$

### Vector Projection ([[1E. Vector - Basics Explanation (2D)#Vector projection explanation|Info]])

**Project $\vec{b}$ onto $\vec{a}$,**

General:

$$
proj_{\vec{a}}\vec{b} = \frac{\vec{b}\cdot\vec{a}}{\|\vec{a}\|^2}\vec{a}
$$

If $\vec{a}$ is a unit vector:

$$
proj_{\vec{a}}\vec{b} = (\vec{b}\cdot\hat{a})\hat{a}
$$

### Checking if moving towards a point

#### Only 1 point moving

![[Vector 2D - Drawings.excalidraw#^frame=l7JK3qKFvl6mj_E2Kq6C_]]
Get a vector $\vec{QP}$,
Find $\vec{QP}\cdot \vec{v}$
At $Q$ ,  Result < 0, angle is < 90$^{\circ}$ so moving **towards**
At $Q_{1}$, Result = 0, angle is = 90$^{\circ}$. Neither moving towards/away. This is will only happen for a split second
At $Q_{2}$, Result > 0, angle is > 90$^{\circ}$ so moving **away**

#### 2 points moving

![[Vector 2D - Drawings.excalidraw#^frame=skYpDphAmivnFiIcdeR9o]]

1. Assume Q is stationary **relative** to P
2. Find P's relative velocity to Q ($v_{1}+v_{2}$)
3. Get dot product
4. Check if dot product > 0 or < 0
   - \> 0 $\implies$ Moving towards
   - < 0 $\implies$ Moving away

> [!NOTE]- What it means by relative
> Imagine P and Q are cars at a intersection. And you are sitting in car P.
> From my perspective, Car Q moves towards me relative to my (Car P) current speed.

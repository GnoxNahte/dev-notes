## Laws

For $a,b\neq 0$

| Name                | Formula                                          |
| ------------------- | ------------------------------------------------ |
| Product             | $a^m\times a^n=a^{m+n}$                        |
| Quotient            | $a^m\div a^n=a^{m-n}$                          |
| Power of Power      | $(a^m)^n=a^{mn}$                               |
| Power of Product    | $(ab)^m=a^mb^m$                                |
| Power of Quotient   | $\left( \frac{a}{b} \right)^m=\frac{a^m}{b^m}$ |
| Negative Exponent   | $a^{-m}=\frac{1}{a^m}$                         |
| Fractional Exponent | $a^{m/n}=\sqrt[n]{ a^m }$                      |
| Zero Exponent       | $a^0=1$                                        |
| Identity Exponent   | $a^1=a$                                        |

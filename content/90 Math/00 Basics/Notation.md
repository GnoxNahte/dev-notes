## Symbols
- $\mathbb{R}$ - Set of all real numbers
- $\mathbb{Z}$ - Set of integers
- $\epsilon$ - is an element of set. E.g. $x \ \epsilon \ \mathbb{Z}$ means x is an element of integer set
- $\mathbb{N}$ - Set of natural numbers (Any integers starting from 1)

## Terminology
- **Domain**: Range of input - $x$
- **Range**: Range of result - $y$

Given: $f(x) = \sqrt{ x }$
- Domain: $[0, \infty)$
- Range: $[0, \infty)$

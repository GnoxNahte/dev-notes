## 2D

| Shape                             | Perimeter     | Area                                          | Notes                                                                            |
| --------------------------------- | ------------- | --------------------------------------------- | -------------------------------------------------------------------------------- |
| Rectangle/<br>Parallelogram       | $2(w+h)$      | $w\times h$                                   |                                                                                  |
| Triangle                          | Add all sides | $\frac{1}{2}bh$ or <br>$\frac{1}{2}ab\sin{C}$ | [[90 Math/01 Trigonometry/Trigonometry]]                                                                 |
| Trapezium                         | Add all sides | $\frac{b_{1}+b_{2}}{2}h$                      |                                                                                  |
| Regular Polygon<br>(e.g. Hexagon) | $n\times s$   | $\frac{1}{2}nsh$                              | $n$ - Number of sides<br>$s$ - Length of side<br>h - height of a single triangle |
| Circle                            | $2\pi r$      | $\pi r^2$                                     |                                                                                  |
| Ellipse                           | -             | $\pi ab$                                      | $a$ - Radius of short axis<br>$b$ - Radius of long axis                          |

## 3D

| Shape    | Surface Area                                                  | Volume                | Notes                                      |
| -------- | ------------------------------------------------------------- | --------------------- | ------------------------------------------ |
| Cube     | $6s^2$                                                        | $s^3$                 |                                            |
| Cuboid   | $2(lw+lh+wh)$                                                 | $l\times w\times h$   |                                            |
| Cone     | $\pi r(r+l)$                                                  | $\frac{1}{3}\pi r^2h$ | $l$ - slant height<br>$l=\sqrt{ r^2+h^2 }$ |
| Pyramid  | $\text{Base Area} \times \text{Perimeter} \times\frac{1}{2}l$ | $\frac{1}{3}Ah$       | $l$ - slant height                         |
| Cylinder | $2\pi hr^2$                                                   | $\frac{4}{3}\pi r^2h$ |                                            |
| Sphere   | $4\pi r^2$                                                    | $\frac{4}{3}\pi r^3$  |                                            |

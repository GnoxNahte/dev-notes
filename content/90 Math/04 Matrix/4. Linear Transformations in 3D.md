Matrix in 3D is the same concept in [[90 Math/04 Matrix/2. Matrix and Linear Transformation\|2D]]. Only adds the z-axis

## Transformation Types
### Summary

| Type                           | Matrix                                                                                                              | Inverse Matrix (reverse transformation)                                                                             | Relation between matrix and it's inverse                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Projection<br>(on a plane)     | $A = I - \frac{1}{\|\vec{n}\|^2}\vec{n}\ \vec{n}^T$                                                                 | Doesn't exist                                                                                                       | Inverse doesn't exist <br>as Projection compresses all points onto 1 line, losing information. |
| Reflection<br>(across a plane) | $M = I - \frac{2}{\|\vec{n}\|^2}\vec{n}\ \vec{n}^T$                                                                 | $A = I - \frac{2}{\|\vec{n}\|^2}\vec{n}\ \vec{n}^T$                                                                 | Inverse is the same matrix as it reflects back on the same line                                |
| Scaling                        | $M = \begin{bmatrix}a & 0 & 0 \\ 0 & b & 0 \\ 0 & 0 & c\end{bmatrix}$                                               | $M = \begin{bmatrix}a^{-1} & 0 & 0 \\ 0 & b^{-1} & 0 \\ 0 & 0 & c^{-1}\end{bmatrix}$                                |                                                                                                |
| Rotation <br>(x-axis)          | $M = \begin{bmatrix}1 & 0 & 0 \\ 0  & \cos{\theta} & -\sin{\theta} \\ 0 & \sin{\theta} & \cos{\theta}\end{bmatrix}$ | $M = \begin{bmatrix}1 & 0 & 0 \\ 0  & \cos{\theta} & \sin{\theta} \\ 0 & -\sin{\theta} & \cos{\theta}\end{bmatrix}$ | Matrix rotates anti-clockwise,<br>Inverse matrix rotate clockwise                              |
| Rotation <br>(y-axis)          | $M = \begin{bmatrix}\cos{\theta} & 0 & \sin{\theta} \\ 0 & 1 & 0 \\ -\sin{\theta} & 0 & \cos{\theta}\end{bmatrix}$  | $M = \begin{bmatrix}\cos{\theta} & 0 & -\sin{\theta} \\ 0 & 1 & 0 \\ \sin{\theta} & 0 & \cos{\theta}\end{bmatrix}$  | Matrix rotates anti-clockwise,<br>Inverse matrix rotate clockwise                              |
| Rotation <br>(z-axis)          | $M = \begin{bmatrix}\cos{\theta} & -\sin{\theta} & 0 \\ \sin{\theta} & \cos{\theta} & 0\\ 0  & 0 & 1\end{bmatrix}$  | $M = \begin{bmatrix}\cos{\theta} & \sin{\theta} & 0 \\ -\sin{\theta} & \cos{\theta} & 0\\ 0  & 0 & 1\end{bmatrix}$  | Matrix rotates anti-clockwise,<br>Inverse matrix rotate clockwise                              |
| Rotation around vector         | $M = \frac{1 - \cos{\theta}}{\|\vec{v}\|^2}\vec{v}\ \vec{v}^T + (\cos{\theta})I_3+\frac{\sin{\theta}}{\|v\|}C_v$    | $-\sin{\theta}$? #todo                                                                                              | -ve theta                                                                                      |
| Shear <br>(along axis)         | $M = \begin{bmatrix}1 & a & 0\\0 & 1 & 0\\0 & 0 & 1\end{bmatrix}$                                                   | -a? #todo                                                                                                           |                                                                                                |
| Shear <br>(along plane)        | $M = I + \frac{1}{\|\vec{n}\|}\vec{v}\ \vec{n}^T$                                                                   | $M = I - \frac{1}{\|\vec{n}\|}\vec{v}\ \vec{n}^T$                                                                   |                                                                                                |
> [!NOTE] Identity matrix here is the 3x3 identity matrix

Compare with [[90 Math/04 Matrix/2. Matrix and Linear Transformation#Summary\|2D]]:

| Type               | 2D                | 3D                                                                 |
| ------------------ | ----------------- | ------------------------------------------------------------------ |
| Projection         | Onto line         | Onto plane                                                         |
| Reflection         | Across line       | Across plane                                                       |
| Scale              | -                 | -                                                                  |
| Rotation           | Rotation 'z-axis' | Different rotation for different axis.<br>Note y-axis is different |
| Shear (along axis) | -                 | -                                                                  |
| Shear (along line) | -                 | -                                                                  |

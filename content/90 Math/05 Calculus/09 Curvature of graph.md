See how x = a changes

| When..                                        | What happens                                                          |
| --------------------------------------------- | --------------------------------------------------------------------- |
| $f'(x)=0$                                     | $f(x)$ reaches max/min, tangent line is horizontal                    |
| $f''(x)=0$ <br>($f'(x)$ also reaches max/min) | $f(x)$ changes from *curve upward* to *curve downwards* or vice versa |

> [!NOTE] $x=0$ is NOT and inflection point
> can test by doing:
> - $f''(-1)$ < 0
> - $f''(1)$ < 0
> 
> Since both are $<0$, both curve down and aren't an inflection point
